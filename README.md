## 🌟 Descripción General

Plataforma interactiva de divulgación, docencia y experimentación en **Inteligencia Artificial de Vanguardia**, diseñada para estudiantes de **Licenciatura, Especialidad, Maestría y Posgrado/Doctorado**.

Integra demostradores en tiempo real, simuladores algorítmicos aplicados a la medicina y las finanzas, un glosario interactivo de **Conceptos de IA con síntesis de voz femenina**, y dos agentes conversacionales de voz y texto con **OpenAI GPT-4o-mini** y **ElevenLabs**.

---

## 🚀 Módulos y Oferta Académica

### 1. 📊 Licenciatura en Contaduría Pública y Finanzas con IA
* **GatedTabTransformer:** Modelos neuronales de atención tabular para auditoría predictiva y conciliación masiva de estados contables.
* **Detección de Anomalías Fiscales:** Detección de discrepancias en XML del SAT utilizando autoencoders y algoritmos *Isolation Forest*.
* **Proyección de Flujo de Efectivo:** Series temporales multivariadas (*DeepAR* y *Temporal Fusion Transformers*) para la gestión de liquidez.

### 2. 🏥 Especialidad en IA Aplicada a los Servicios de Enfermería
* **Clara IA & Automatización del PAE:** Sistema interactivo que guía la valoración, diagnóstico, planeación, ejecución y evaluación conforme a taxonomías clínicas **NANDA / NIC / NOC**, reduciendo hasta un 80% la carga administrativa en piso.
* **Procesamiento de Lenguaje Natural Clínico:** Asistente seguro para la estructuración y síntesis de notas de evolución médica con total privacidad hospitalaria.

### 3. ⚡ Especialidad en IA Generativa y sus Aplicaciones
* **Ingeniería de Prompts Avanzada:** Arquitectura de prompts multi-paso, técnicas *Few-Shot*, *Chain-of-Thought* (CoT) y *Tree of Thoughts* (ToT).
* **Embeddings y Búsqueda Semántica:** Vectorización de corpus corporativos y bases vectoriales de alta escala.
* **Gobernanza ISO/IEC 42001:** Políticas de despliegue responsable y mitigación de sesgos.

### 4. 🏢 Maestría en IA Aplicada en la Administración de Hospitales
* **Optimización de Recursos Hospitalarios:** Algoritmos heurísticos y de optimización entera para la asignación dinámica de quirófanos y camas censables.
* **Triaje Inteligente en Urgencias:** Modelos predictivos de clasificación rápida para estimar gravedad y tiempo de espera prioritario.

### 5. 🔬 Tesis Doctoral: Agentes Autónomos & Mixture of Experts (MoE)
* **Línea de Investigación Doctoral:** *Agentes de IA con MoE (Mixture of Experts y sus variantes) y Ecosistemas Multiagente para el Seguimiento Farmacoterapéutico en Pacientes de Tabasco, México*.
* **Stack Especializado:** LangChain, LangGraph, LangGraph-Swarm, LangSmith, Langflow, n8n y ElevenLabs.
* **Simulador MoE:** Router dinámico de activación dispersa (*Sparse Gating*) que deriva tokens y consultas clínicas a sub-redes especialistas en farmacología, adherencia terapéutica y fitoterapia local.

## 📚 Glosario Interactivo: Conceptos de IA con Voz

Colección de 21 tarjetas pedagógicas clasificadas en 3 niveles de dominio con lectura automática en **voz femenina** al hacer clic:
* **Básicos:** Modelo Base de IA, Prompt, System Prompt, Temperatura, Embeddings Semánticos, Fine-Tuning.
* **Intermedios:** RAG (Retrieval-Augmented Generation), Agente Autónomo, Human-in-the-Loop (HITL), Guardrails, Tokenización BPE.
* **Avanzados:** GraphRAG (Grafos Neo4j), Sistemas Multiagente (LangGraph-Swarm), Transformers & Self-Attention, Mixture of Experts (MoE), Jailbreaking & Red Teaming.

## 💻 Tecnologías Utilizadas

* **Frontend:** HTML5 Semántico, CSS3 Vanilla (Glassmorphism, variables CSS, gradientes HSL y microanimaciones de audio).
* **Responsive Design:** 100% adaptable para Teléfonos Móviles, Tabletas, Computadoras de Escritorio y Pantallas 4K.
* **Audio & IA:** 
  * SDK `@11labs/client` via ESM para telefonía conversacional.
  * Web Speech API (`SpeechRecognition` y `SpeechSynthesis`).
  * OpenAI Chat Completions API (`gpt-4o-mini`).
* **Seguridad:** Aislamiento de llaves en variables de entorno local (`.env`) y `localStorage`, sin exposición de credenciales en el repositorio.

## 🛠️ Instalación y Uso Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/TerceroMaster/chapultepec-clases-ia.git
   cd chapultepec-clases-ia
   ```

2. **Abrir en el navegador:**
   * Puedes usar cualquier servidor local ligero, por ejemplo con Node.js:
     ```bash
     npx serve -l 3000
     ```
   * O con la extensión **Live Server** de VS Code / Antigravity IDE.

3. **Configurar API Keys (Opcional para modo live):**
   * Haz clic en el botón de engranaje ⚙️ de la barra de navegación para ingresar tu propia OpenAI API Key o ElevenLabs Agent ID.
   * La plataforma cuenta con un repositorio inteligente precargado para funcionar sin llaves externas.
